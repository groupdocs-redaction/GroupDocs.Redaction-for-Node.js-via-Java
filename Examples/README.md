# GroupDocs.Redaction for Node.js via Java — Examples

Code samples mirroring [GroupDocs.Redaction for Java Examples](https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-Java), structured like [GroupDocs.Viewer for Node.js via Java](https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-Node.js-via-Java).

## Requirements

- Node.js 20+
- JRE/JDK 8+ (`JAVA_HOME` set)
- npm package `@groupdocs/groupdocs.redaction` (26.10+)

## Setup

```bash
cd Examples
npm install
```

Place a `.lic` file in `license/` (optional; otherwise evaluation mode).

## Run

```bash
npm start
# or a single example:
node --import ./utils/apply-license.js quick-start/hello-world.js
```

Sample files live under `Resources/SampleFiles/`. Outputs go to `output/`.

## Layout

| Folder | Corresponds to Java |
