# GroupDocs.Redaction for Node.js via Java

[![banner](https://raw.githubusercontent.com/groupdocs/groupdocs.github.io/master/img/banners/groupdocs-redaction-common-banner.png)](https://products.groupdocs.com/redaction/nodejs-java/)

GroupDocs.Redaction for Node.js via Java removes sensitive text, metadata, annotations, and image areas from Word, Excel, PowerPoint, PDF, images, and related formats — via the same Java API, called from Node.js.

## Examples

See [`Examples/`](Examples/) for a full set of samples aligned with GroupDocs.Redaction for Java (ESM layout like GroupDocs.Viewer for Node.js via Java).

```bash
cd Examples
npm install
npm start
```
